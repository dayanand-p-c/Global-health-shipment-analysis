# Global Health Supply Chain: Cost & Delivery Analysis

A data cleaning and business analytics project built on real USAID/PEPFAR shipment data, health commodity shipments moved between 2005 and 2013 under one of the largest global health procurement programs ever run. The raw dataset arrives broken, mixed-type numeric columns, placeholder text in date fields, no analysis possible until it's actually cleaned. This project documents that cleaning process, then answers a real supply chain question with the result.

Built with SQL, Python, and Tableau. Dataset: [Supply Chain Shipment Pricing Dataset, USAID Development Data Library](https://data.usaid.gov/HIV-AIDS/Supply-Chain-Shipment-Pricing-Dataset/a3rc-nmf6), released under CC-BY.

**Note on data limitations:** USAID's own documentation states that conclusions about cost or lead time for specific line items or narrow product/country cuts should not be treated as precise. This analysis focuses on aggregate patterns, not individual shipment-level claims, in line with that guidance.
